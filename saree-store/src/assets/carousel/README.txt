Drop the 5 homepage carousel images in this folder.

Accepted formats: .jpg .jpeg .png .webp
Name them 1.jpg, 2.jpg, 3.jpg, 4.jpg, 5.jpg to control the order (any names work,
but numbered names keep the order predictable).

The carousel is built for 5 slides. If you add fewer than 5 images, the existing
ones repeat to fill the remaining slots. If this folder is empty, the carousel
still shows its 5 titles over a placeholder background until you add images.

To change a slide's title, edit the `slides` array in src/pages/Home.jsx.
